# 新版工作台交付说明

## 入口与边界

- 新版：`http://127.0.0.1:5173/studio.html`。
- 旧版：`http://127.0.0.1:5173/`，保留为迁移期间的完整功能入口，顶部可进入新版。
- 新版代码集中在 `src/coalplan/web1.0/src/studio/`；与旧版共用 API、任务中心、依赖和 Vite 服务，生产构建同时输出两个 HTML 入口。
- 文档编写与知识管理是操作空间划分，不是已实现的账号权限隔离。

## 实际工作管线

编写人员：项目选择/创建 → 追加投标资料与项目补充信息 → 分阶段目录规划与人工编辑 → 确认写作任务和依据 → 章节生成与 Markdown 编辑 → 候选版本比对选用 → 审查与导出。

管理人员：批量导入优秀施组 Markdown → 后台 V2 切分及筛选 → 查看候选正文、参数、标签和适用边界 → 批量发布/排除 → 编写阶段匹配已发布原子。

投标资料提供项目事实；参考原子提供工艺与控制逻辑；写作技巧控制组织表达；规范用于审查。四类内容不混为项目事实。

## 已实现的交互

- 固定导航与项目状态栏，桌面工作区独立滚动，手机导航与表单自动换行。
- 项目和页面通过 URL 恢复；章节选择及未提交正文草稿在本机浏览器保存。浏览器存储不足时提示立即提交版本。
- 项目资料采用紧凑多文件上传，每份资料可打开章节列表，再查看对应原文。
- 目录支持搜索、节点内容编辑、新增、排序与删除确认；AI 提案须预览后应用，支持快照撤销。分阶段规划沿用已有任务接口。
- 章节工作区采用成熟 Markdown 编辑器，支持编辑、预览、左右对照与滚动同步；保存产生候选版本，比较后才选用。未实现逐字符预览定位，不将滚动同步描述为精确定位。
- 写作任务与写作技巧独立编辑；参考原子提供筛选、分页索引、详情和固定选择。AI skill 通过字段表单编辑，不要求编写 JSON。
- 多章节生成可配置章节并行数，任务中心复用现有暂停、恢复与进度接口。
- 成稿可查看、合并、下载当前 Markdown；审查结果以问题清单展示。
- 原子管理显示真实 V2 内容、参数化模板、变量、适用边界和来源；支持批量发布/排除。

## 实际后端衔接修复

1. 优秀施组批量导入接入 V2 切分，失败批次保留成功原子；重试不覆盖已审核或发布的同标识原子。
2. 投标上传新增 `append` 模式，新版默认追加；同名资料替换该文件，其他文件保留。旧同步调用默认行为不变。
3. 新增按来源文件查询其章节列表接口，避免多个文件的来源内容串联展示。
4. 自动原子匹配失败时，仍保留有效的用户固定原子；排除项、未发布项及有发布阻塞的 V2 原子不进入提示词。
5. SQLite 启用 WAL 与 30 秒连接等待，减少后台写入和界面读取之间的锁冲突。备份运行中数据库应使用 SQLite backup API 或停服后完整备份，不应只复制主 DB 文件而忽略 WAL。

- `python -m unittest tests.integration.test_studio_bridge`：4 项通过，覆盖多来源追加与原文查询、V2 重试保护、WAL 并发读取、匹配失败保留用户固定项。

- 本轮没有发起真实付费 LLM 调用，没有恢复用户已暂停的生成任务；浏览器测试项目为独立副本，完成后清理。

## 运行

后端在项目根目录设置 `PYTHONPATH=src`，执行 `python -m uvicorn coalplan.main:app --host 127.0.0.1 --port 8010`。

前端在 `src/coalplan/web1.0` 执行 `npm run dev -- --host 127.0.0.1 --port 5173`，打开新版入口。此次未更改服务器部署或推送 GitHub。
